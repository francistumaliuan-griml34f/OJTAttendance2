# OJT Attendance (Android)

Open this folder in Android Studio (Koala or newer), let Gradle sync, then Run or Build > Build APK(s).
Requires Android 8.0+ and Google Play services (for location).

- First launch needs internet once to sync Philippine Time (also after every phone restart).
- Photos and records are stored privately inside the app (uninstalling deletes them). Use "Export PDF" regularly as a backup.
